    Этот раздел содержит модели данных и протоколы обмена данными с определением акторов и транзакций. Он является частью машиночитаемого представления знаний уровня L3.

    Страницы, включённые в этот раздел, описаны ниже.

    • Акторы — перечень и описание программных или человеческих субъектов, взаимодействующих с системой, полученные на основе бизнес-требований, определённых на уровне L2.
    • Диаграммы последовательности — диаграммы последовательности, отображающие взаимодействия между системными акторами в порядке их выполнения, полученные на основе бизнес-процессов уровня L2.
    • Транзакции — определённый перечень системных транзакций на атомарном уровне для каждого актора с описанием, описаниями возможностей (capability statements), определениями структур, опросниками, пакетами документов и композициями. Может также содержать ссылки на транзакции в других руководствах по внедрению.
    • Индикаторы и показатели — тематический перечень индикаторов, определённых в руководстве по внедрению, со ссылками на руководящие документы уровней L1 и L2.

    Проектная документация -ПРОЕКТ-

    В приведённой ниже документации подробно описано, как использовать этот IG для исполнения логики принятия решений, а также необходимые для этого ресурсы, включая PlanDefinitions, ActivityDefinitions, ValueSets и Libraries.

    PlanDefinitions

    Эти ресурсы PlanDefinitions можно найти в указателе артефактов

    ActivityDefinitions

    Для представления действий, которые необходимо выполнить, настоящее руководство по внедрению следует шаблонам рабочих процессов, установленным базовой спецификацией FHIR. Каждый антиген, представленный в виде PlanDefinition, обрабатывается для получения ресурсов ActivityDefinitions, соответствующих руководству по внедрению FHIR Clinical Practice Guidelines CPG-ActivityProfiles.

    FHIR Library

    FHIR Library содержит закодированную в base64 библиотеку CQL, которая представляет логику принятия решений в виде ряда логических условий. Каждый ресурс PlanDefinition и Measure ссылается на ресурс Library, на основе которого может приниматься каждое решение, и указывает, какое выражение CQL используется для инициирования решения в PlanDefinition или откуда извлекаются данные для создания MeasureReport в Measure соответственно.

    ValueSets

    Многие наборы значений (ValueSets), используемые в этом IG, взяты из CPG on FHIR и IPS. Ряд наборов ValueSets сгенерирован на основе пользовательских сценариев, подробно описанных в этом IG.

    Из этого формата есть одно исключение — библиотеки вакцин, которые устанавливают соответствие кодов между различными системами, включая SNOMED GPS и ATC ВОЗ, чтобы разработчики могли искать любую вакцину, которая может быть применима для их пользователя. Подробнее этот подход описан ниже.
